A missing VALKEY_URL or JWT_SECRET does not fail this install and does
not fail the probes. It fails every sign-in with a 500, because the
login path checks the lockout counters before verifying a password and
refuses to issue an unsigned token. A missing MG_SERVICE_API_KEY does
not fail this install or the probes either -- it fails the
model-gateway's very next key-verification call with a 500, because
require_mg_service_key has no static-key fallback the way
require_service_key does. That value must be identical to the
model-gateway release's secret.orgVerifyApiKey.
